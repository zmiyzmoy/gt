# Покерный ИИ с использованием Reinforcement Learning

Система обучения покерного агента с использованием Reinforcement Learning на базе Ray, RLlib, PyTorch и OpenSpiel.

## Особенности проекта

- Обучение агента для игры в покер с использованием PPO (Proximal Policy Optimization)
- Поддержка покера с несколькими игроками (максимум 8)
- Отслеживание статистики оппонентов для адаптации стратегии
- Оптимизация использования ресурсов (CPU/GPU)
- Мониторинг памяти и производительности
- Интеграция с Weights & Biases для отслеживания процесса обучения

## Структура проекта

- `environment_fixed.py` - Среда покера на базе OpenSpiel с поддержкой Gymnasium API
- `models_fixed.py` - Нейронная сеть (AdvancedPokerModel) для обучения агента
- `train_fixed.py` - Скрипт для обучения с использованием PPO и Ray/RLlib
- `config.py` - Конфигурация игры и параметров обучения
- `loggers.py` - Логирование в Weights & Biases
- `test_env.py` - Тестирование работоспособности среды
- `debug.py` - Утилиты для отладки и диагностики

## Настройка конфигурации

Основные параметры можно настроить в файле `config.py`:

- Количество игроков (`num_players`)
- Размер начального стека (`starting_stack`)
- Размеры блайндов (`small_blind`, `big_blind`)
- Параметры обучения (learning rate, batch size, и т.д.)

## Решение проблем

### Ошибка размерности наблюдений

Если возникает ошибка размерности наблюдений, проверьте:
1. В файле `models_fixed.py` правильно ли определяется размер входа `self.obs_size`
2. В `environment_fixed.py` правильно ли формируется наблюдение в методе `_get_observation()`

### Утечки памяти

При утечках памяти:
1. Уменьшите количество воркеров в `TrainingConfig.num_workers`
2. Уменьшите размер батча `TrainingConfig.train_batch_size`
3. Используйте меньше сред на одного воркера `TrainingConfig.num_envs_per_worker`
